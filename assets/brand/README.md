# AEUI 로고

기본 로고는 소문자 `aeui`를 붙여 쓴 워드마크입니다. 글자는 회색이며 `i`의 점에는 코랄색을 사용합니다.

## 파일

[aeui-logo-wordmark.svg](./aeui-logo-wordmark.svg)는 투명 배경의 기본 워드마크입니다. viewBox는 232.25 × 120이며, 직접 작성한 SVG 경로와 도형으로 구성해 외부 폰트나 이미지에 의존하지 않습니다.

## 색상과 크기

| 요소 | 색상 |
| --- | --- |
| 글자 | `#77777D` |
| `i`의 점 | `#EA5860` |

밝은 배경과 어두운 배경에 같은 색상을 사용합니다. 너비 96px 이상을 권장하며, SVG 비율과 내부 여백을 유지합니다.

## 적용 위치

- 랜딩 페이지 헤더·푸터와 브라우저 탭 아이콘
- 저장소 README와 문서 인덱스

모두 `aeui-logo-wordmark.svg`를 공통 원본으로 참조합니다. 랜딩 페이지 빌드 시 Vite가 로고를 배포 결과에 포함하며, 브랜드 파일 변경도 GitHub Pages 빌드 대상입니다.
