A EASY UI

let으로
만드는 화면.

AEUI는 JavaScript 변수로 상태를 관리하는
프론트엔드 프레임워크입니다.
변수의 값을 바꾸면 화면도 바뀝니다.

프로젝트 만들기 ↗예제 살펴보기 ↓

AEUI는 현재 개발 중이며, API와 동작이 변경될 수 있습니다.

Counter.jsxAEUI
export default function Counter() {
  let count = 0;

  return (
    <button onClick={() => count++}>
      클릭: {count}
    </button>
  );
}

예제의 코드를 수정하고 실행 결과를 확인할 수 있습니다.

let

변수를 바꾸면 화면이 바뀝니다.

let으로 상태를 선언하고 count++처럼 값을 바꾸세요. 상태를 바꾸는 별도 함수가 필요하지 않습니다.

버튼 클릭이나 입력으로 값을 바꾸면 화면에 자동으로 반영됩니다.

직접 해보기count++를 count += 5로 바꾸고 버튼을 눌러보세요.

array / object

배열 안의 값도 직접 바꿉니다.

cart[0].quantity++처럼 배열 안 객체의 값을 바로 바꾸세요. 새 배열을 만들거나 상태 갱신 함수를 호출할 필요가 없습니다.

직접 해보기버튼을 눌러 커피 수량을 늘려보세요.

watch

상태가 바뀌면 코드를 실행합니다.

watch에 실행할 함수와 관찰할 값을 지정하세요. 아래 코드는 dark가 바뀔 때 화면 테마를 바꿉니다.

직접 해보기버튼을 눌러 밝은 테마와 어두운 테마를 전환해 보세요.

let + props

한 컴포넌트에서 props와 let을 함께 씁니다.

Order는 가격을 price props로 받고, 수량은 자체 let quantity로 관리합니다. 가격과 수량 중 어느 쪽이 바뀌어도 합계에 반영됩니다.

직접 해보기수량을 늘린 뒤 할인을 적용해 보세요. 수량은 유지되고 새 가격으로 합계가 바뀝니다.
