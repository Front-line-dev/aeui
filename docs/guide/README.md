## 목차

| 문서 | 한 줄 요약 |
|---|---|
| [01. 시작하기](01-getting-started.md) | 프로젝트 생성부터 첫 화면 띄우기까지 |
| [02. 컴포넌트](02-components.md) | 함수형 컴포넌트 작성법, setup과 render의 분리, props |

| [05. 라우팅](05-routing.md) | 파일 기반 라우팅, 동적 경로, 레이아웃, 404 페이지 |
