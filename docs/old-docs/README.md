# 이전 문서 보관소

이 폴더는 현재 문서 체계를 만들기 전에 작성한 자료를 보존한다. 여기 있는 `spec.md`와 `feature-to-be-implemented.md`를 포함한 모든 파일은 현재 스펙, 구현 상태 또는 계획 목록이 아니다.

- 현재 규칙: [`docs/spec`](../spec/README.md)
- 알려진 구현 결함과 계획: [`docs/tracking`](../tracking/README.md)
- 사용자 설명: [`docs/guide`](../guide/level-1.md)

이전 결정의 배경을 조사할 때만 참고하며, 내용을 현재 문서에 반영하려면 실제 소스와 현재 스펙을 다시 확인한다.
